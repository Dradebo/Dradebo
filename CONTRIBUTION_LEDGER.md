## Evidence rules

A project moves into **Verified contribution** only when at least one of these exists:

- an authored pull request;
- an attributable commit on the externally owned repository;
- a public maintainer acknowledgement;
- a contract, employer record, or project record that can be described safely;
- an attributable fork comparison supported by authored commits.

Repository access, branch divergence, or possession of a copy is not sufficient by itself.
