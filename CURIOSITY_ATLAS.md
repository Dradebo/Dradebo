# Curiosity Atlas

This Atlas is a curated public map of 36 representative repositories across 12 recurring areas of inquiry. Inclusion does not imply authorship of upstream projects.

## 1. Agents that can operate

- **Owned:** `Dradebo/dhis2-mcp` — domain-specific agent tooling for DHIS2.
- **Observed:** `Dradebo/letta` — persistent agent memory and tool orchestration.
- **Observed:** `Dradebo/UI-TARS` — computer-use agents and visual interface control.

**Question:** How can agents gain tools, memory, and operational judgement without becoming unsafe dependency tangles?

## Relationship discipline

- **Owned** does not necessarily mean production-ready.
- **Contributed** requires public authorship evidence.
- **Adapted** requires verified attributable divergence from upstream.
- **Observed** means retained for study, testing, comparison, or possible integration.

Fork divergence alone is not treated as proof of personal authorship.
