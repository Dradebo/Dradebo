# Sean Ash / Dradebo

I build tools at the intersection of public-interest data systems, local-first software, creative computing, personal knowledge, and low-cost physical technology.

This GitHub account is both a workshop and a research archive. It contains owned products, professional contributions, experiments, and upstream projects saved while investigating recurring technical questions.

## Navigate the account

- [Curiosity Atlas](CURIOSITY_ATLAS.md) — a curated map of 36 representative repositories across 12 recurring areas of inquiry.
- [Contribution Ledger](CONTRIBUTION_LEDGER.md) — externally owned work that can be supported by public authorship evidence, plus an explicit verification queue.
- [Atlas data](atlas/nodes.json) — the machine-readable form of the public Atlas.

## Attribution rule

A repository appearing under this account does **not** automatically imply that I created or contributed to the upstream project.

The public curation uses four relationship labels:

- **Owned** — a project I own or lead.
- **Contributed** — externally owned work supported by public contribution evidence.
- **Adapted** — a fork containing verified changes attributable to me.
- **Observed** — an upstream project retained for study, testing, comparison, or future integration.

Where authorship cannot yet be demonstrated, the label remains **Observed** or **Verification pending**.

## Current operating principle

> Building is not complete when the code works. It is complete when the work has credible proof, a clear audience, and an appropriate next action.

This profile is being curated under that rule: fewer unsupported claims, clearer evidence, and a deliberate separation between products, contributions, and curiosity.
